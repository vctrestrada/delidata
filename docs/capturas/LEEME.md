# Capturas para el README

Guarda aquí las capturas con estos nombres para que aparezcan en el README:

- `dashboard.png` — Dashboard del dueño (últimos 30 días, todo el negocio)
- `punto-de-venta.png` — Punto de venta con algunos productos en la venta
- `recorrido.png` — Cualquier pantalla con un globo del recorrido guiado abierto
- `gastos.png` — Pantalla de gastos con el resumen por categoría

Tamaño recomendado: 1440 × 900.
